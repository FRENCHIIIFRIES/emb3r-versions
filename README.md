## Notes

- **Windows** builds are unsigned, so SmartScreen shows a warning on first run:
  *More info → Run anyway*.
- **macOS** builds are ad-hoc signed, so Gatekeeper blocks the first launch:
  *System Settings → Privacy & Security → Open Anyway*.
- Every release also ships `.zip` builds and the `latest*.yml` update feeds that the
  in-app updater reads. They're on each release page, linked above.
- Older versions are kept for reference and reproducibility. They do not receive fixes —
  if you're just here to use emb3r, take the latest.

Total archived across all 32 releases: **25.2 GB**, hosted on the main repository.
